## 調研方法（從第 3 週講義抽取）

### 步驟 1：從顧客 Persona 推導旅程起終點
從顧客 Persona 的使用情境推導旅程的起點和終點。起點是顧客開始有需求的時刻，終點是需求被滿足的時刻。

### 步驟 2：劃分 3-5 個階段
依顧客行為的自然轉換劃分階段。每個階段是顧客做的一件事。劃分原則：同質性高的行為合併為一個階段。

### 步驟 3：填入行動與接觸點
每個階段填入：顧客做什麼（行動）、透過什麼接觸（接觸點）。接觸點分為數位、實體、人際三類。

### 步驟 4：評估情緒畫曲線
每個階段評估情緒分數（+3 到 -3）。推導方法：從 Persona 的期望/不期望感受推導——如果階段滿足了期望感受→正面，如果觸發了不期望感受→負面。標注為「教學推估」（非實測）。

### 步驟 5：找痛點寫機會
每個階段找痛點（顧客的挫折），寫改善方向（機會）。每個改善方向標注下游影響（影響功能或風格）。最低情緒點的痛點是下游設計最優先解決的目標。
