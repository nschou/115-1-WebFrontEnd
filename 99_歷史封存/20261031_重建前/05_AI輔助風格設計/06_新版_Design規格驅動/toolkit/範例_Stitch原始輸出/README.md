# 範例：Stitch 原始輸出（New-Style_C）

> 這是「工具吐出來的樣子」，**未經整理**。放在這裡的目的：讓學生看到「原始 vs 完成」的差距。

| 檔案 | 說明 |
|---|---|
| `New-Style_C/balanced_modern_morning/DESIGN.md` | Stitch 匯出的 DESIGN.md：**YAML ＋ 7 章**（Brand & Style／Colors／Typography／Layout & Spacing／Elevation & Depth／Shapes／Components） |
| `New-Style_C/_1 … _4/` | 四個畫面的 `code.html` 與截圖（首頁／下單／進度／取餐） |
| `New-Style_C/Style_C_AI-01.md` | 生成時的回覆摘要（設計說明） |

> 原資料夾內的 `stitch_.zip` 是同一批檔案的下載包，未重複複製（省 1.1 MB）。

## 它缺什麼

| 缺 | 為什麼要補 |
|---|---|
| 為什麼這樣設計（設計理由） | 沒有它，AI 不知道何時可以變通；外包也不知道品牌意圖 |
| 動效 | Stitch 只生成靜態畫面 |
| 回溯表 | 沒有它，無法驗收、無法判斷哪些可換 |

→ 補完後的成品見 `../範例_DESIGN_10章_平衡現代/`。
