# 06 Design.md 輸出格式範本

> 本範本只定義 `Design.md` 的**輸出格式**（10 章結構）。
> 方法論見 `06_designmd_README.md`；研究工作表見 `06_designmd_rd_template.md`。
> 學生用版（含填寫說明）見 `../02_附錄A_Designmd十章骨架範本.md`。

---

## DESIGN.md 必須包含的結構

### 0. 前言（不佔章號）

| 欄位 | 填什麼 |
|---|---|
| 版本 | v1.0 |
| 日期 | YYYY-MM-DD |
| 產生模式 | 正常模式（Stitch）／無樣張模式（omp） |
| 產生工具與版次 | Google Stitch，Prompt 版次 P-YYYY-MM-DD-01 |
| 選定預設 | 科技俐落／溫暖信賴／平衡現代 |
| 凍結範圍 | DS-BRAND ~ DS-COMP |
| 人寫範圍 | DS-RATIONALE、DS-MOTION、DS-TRACE |
| 讀者導覽 | 老闆看第 1 章／設計師看 1–9／工程看 frontmatter＋2–8＋10 |
| 遠距顯示 | 見 `DESIGN-DISPLAY.md`（KDS／看板，第 6 週產出；本檔不涵蓋） |

### 1. 設計理由（DS-RATIONALE）

| 小節 | 必要欄位 |
|---|---|
| 1.1 風格一句話定義 | 一句，≤25 字 |
| 1.2 品牌人格 | 形容詞／視覺對應／型別（定律·慣例）／反面案例／來源 |
| 1.3 核心體驗目標 | 目標／放大什麼／避免什麼／來源 |
| 1.4 服務承諾 | CJM 階段／承諾句／來源 |
| 1.5 情緒需求＋不可違反的限制 | 優先序表／限制清單（無障礙·中文可讀·裝置·禁用） |

### 2–8. 凍結區（DS-BRAND／COLOR／TYPE／SPACE／DEPTH／SHAPE／COMP）

| 章 | 章名 | 來源 |
|---|---|---|
| 2 | Brand & Style | 工具原文（逐字） |
| 3 | Colors | 工具原文（逐字） |
| 4 | Typography | 工具原文（逐字） |
| 5 | Layout & Spacing | 工具原文（逐字） |
| 6 | Elevation & Depth | 工具原文（逐字） |
| 7 | Shapes | 工具原文（逐字） |
| 8 | Components | 工具原文（逐字） |

每章下方可加「中文導讀」（3–5 行，學生寫）。**原文不得改寫。**

### 9. 動效原則（DS-MOTION）

| 小節 | 必要欄位 |
|---|---|
| 9.1 節奏檔位 | 快 150／中 200–250／慢 300ms，選一檔＋理由（引用第 1 章） |
| 9.2 動效清單 | 觸發點／目的／時長／緩動／reduced-motion 降級 |
| 9.3 禁止清單 | 至少 4 項 |
| 9.4 不做動效的地方 | 至少 3 項 |

### 10. 回溯表與可替換性契約（DS-TRACE）

| 小節 | 必要欄位 |
|---|---|
| 10.1 回溯表 | 決策／依據／回溯到／驗證狀態／可替換性 |
| 10.2 覆蓋率報告 | N／M／覆蓋率／未覆蓋清單 |
| 10.3 換版程序 | 四步（外包交件→比對底座→merge→重跑） |

---

## 驗證狀態與可替換性（固定用語）

| 欄位 | 只允許這些值 |
|---|---|
| 驗證狀態 | `已驗證`（有實測）／`設計推導`（有依據未測）／`待驗證`（推測） |
| 可替換性 | `不可換（底座）`／`可換（風格）`／`需連動` |
| 型別 | `定律`／`慣例` |
