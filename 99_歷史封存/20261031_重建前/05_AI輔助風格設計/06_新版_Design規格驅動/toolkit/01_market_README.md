## 調研方法（從第 2 週講義抽取）

### 步驟 1：問題/需求假設

在一切分析之前，先問「誰的什麼問題值得被解決？」寫下問題假設：

```
[誰] 在 [什麼情境下] 遇到 [什麼問題/需求]，
這個問題嚴重到他願意付出 [什麼代價] 來交換解法。
```

驗證問題是否值得解決的 3 個判準：
- **頻率**：這個問題多常發生？
- **強度**：不解決會怎樣？
- **付費意願**：願意付出什麼代價？

### 步驟 2：老闆投入意願分析

確認有人（老闆）願意投入資源解決這個問題。分析：
- 為什麼願意解決？（動機）
- 願意投入什麼資源？（能力）
- 承擔什麼風險？（決心）
- 期望什麼回報？（目標）
- 退出條件是什麼？（底線）

### 步驟 3：行業細分分析

1. 收集產業基本數據（市場規模、店家數、成長率）
2. 依商業模式分類（不是依品牌，是依經營邏輯）
3. 找出每種模式的目標客群特徵
4. 分析不同模式的客單價、數位化程度、等待時間、毛利率

關鍵問題：
- 這個行業有幾種不同的經營型態？
- 每種型態的客戶要的是什麼？
- 不同型態之間的差異有多大？

### 步驟 4：選定目標客群

評估面向：
- 系統開發複雜度（適合課程專案嗎？）
- 數位化潛力（哪種型態最需要數位系統？）
- 教學價值（哪種型態能涵蓋最多知識點？）

選定後，記錄為什麼選、為什麼不選其他。

### 步驟 5：約束鏈推導

選定市場後，推導它如何約束後續設計方向。市場選擇約束方向，但不唯一決定每個方案。

## AI 協作（分階段）

### 階段 1：盤點與提問

```
請讀取 @01_market_rd_template.md（研究工作表）。
先盤點已有資料與缺漏，提出本輪需要調查的問題及蒐集方法。
不要直接寫成完整研究結論——先確認調查方向。
```

### 階段 2：蒐集與分析

學生根據 AI 提出的調查方向，蒐集資料（可用 AI 協助蒐集產業數據）。提供資料後：

```
以下是蒐集到的產業資料：
[學生提供資料]

請協助整理為 01_market_rd_template.md 中的六大細分市場比較表。
對每個市場標注資料來源。缺少證據的項目標為待補。
不得假造調查結果或研究數據。
```

### 階段 3：推導與論述

```
請讀取 @01_market_rd.md（目前的研究成果）。
協助完成以下推導：
1. 選定理由（比較6個市場的優劣）
2. 不選其他市場的理由
3. 約束鏈推導
4. 資料性質標注（使用者指定/研究依據/案例假設/設計推導）
標記所有「待確認」項目。輸出更新後的 01_market_rd.md。
```

### 階段 4：整理結論

```
請讀取 @01_market_rd.md（研究推導過程），
以 @01_market_template.md 為產出範本，
產生 01_market.md（結論，按範本格式）。
如果資料不完整，提出問題。
```

|---|---|---|
| 1 | 問題假設 | 包含誰、情境、問題、代價四要素 |
