# 01 市場分析範本（第 2 週）

> 學生根據本範本產生兩個檔案：
> - `01_market.md` — 結論（固定格式，供下游使用）
> - `01_market_rd.md` — 研究推導過程（完整論述，含資料來源）

---

## 01_market.md 需包含的章節

### 1. 選定市場

| 欄位 | 填什麼 | 資料性質 |
|---|---|---|
| 市場名稱 | 細分市場的名稱 | 使用者指定（教授/老闆） |
| 選擇理由 | 為什麼選這個市場（3-5 點） | 研究依據 + 使用者指定 |
| 不選其他市場的理由 | 為什麼不選其他5個 | 研究依據 |

### 2. 六大細分市場比較表

| 細分市場 | 數位化程度 | 客單價 | 系統需求 | 痛點 | 角色分工 | 適合教學 |
|---|---|---|---|---|---|---|
| [市場A] | [高/中/低] | [範圍] | [豐富/中等/少] | [描述] | [描述] | [是/否] |
| ... | ... | ... | ... | ... | ... | ... |
| [選定的市場] | ... | ... | ... | ... | ... | ... |

### 3. 約束鏈

選定市場後，列出如何約束後續設計的方向：

```
選定「[市場名稱]」
→ 目標客群：[描述]
→ 老闆傾向：[描述]
→ 顧客期望：[描述]
→ CJM 情緒需求：[描述]
→ Blueprint 方向：[描述]
→ 風格方向：[描述]（風格假設，需比較驗證）
→ 功能需求：[描述]
```

標注：市場選擇約束方向，但不唯一決定每個方案。

### 4. 案例範圍與假設

| 項目 | 內容 | 來源 |
|---|---|---|
| 示範範圍 | [規模] | 使用者指定 |
| 目標客群 | [描述] | 使用者指定/研究依據 |
| 客單價 | [範圍] | 研究依據 |
| 數位化目標 | [描述] | 案例假設 |
| 人力配置 | [描述] | 案例假設 |
| 啟動資金 | [描述] | 案例假設 |

每項標注來源：`使用者指定`、`研究依據`、`案例假設`。不可把案例假設寫成研究依據。

## 01_market_rd.md 需包含的內容

研究推導過程——記錄學生如何得出上述結論：

### A. 行業研究資料

列出參考的行業分析資料來源（如政府統計、行業報告、新聞報導）：
- 資料名稱、出處、日期
- 從資料中提取的關鍵數據

### B. 六大細分市場分析

每個市場的完整分析：
- 商業模式描述
- 目標客群描述
- 客單價區間（附來源）
- 數位化程度分析
- 代表性 Persona 速覽
- 系統需求評估

### C. 選擇推導過程

- 比較6個市場的優劣
- 為什麼選定這個市場（具體理由）
- 為什麼不選其他5個（具體理由）
- 這個選擇如何約束後續設計（推導鏈）

### D. 資料性質標注

每項關鍵數據標注：
- `研究依據` — 來自行業研究資料
- `使用者指定` — 教授或老闆指定
- `案例假設` — 教學假設，非實測
- `設計推導` — 從上游推導

## 使用方式

### 用 omp

```

根據第2週課程的行業分析和市場選擇，填寫範本。

- 01_market.md（結論，按範本格式）
- 01_market_rd.md（研究推導過程，含資料來源）
如果資料不完整，提出問題。
```

```
[貼入本範本]
請產生 01_market.md 和 01_market_rd.md。
```
