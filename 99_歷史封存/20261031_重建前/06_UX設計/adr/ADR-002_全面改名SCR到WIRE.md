# ADR-002 全面改名：SCR → WIRE（線框）

| 欄位 | 內容 |
|---|---|
| 編號 | ADR-002 |
| 狀態 | **已被 ADR-003 取代**（2026-10-28） |
| 提出者 | 課程教師（觀察到教材混用「SCR／螢幕／線框」） |
| 決策者 | 課程教師 |
| 受影響者 | 修課學生、助教、後續維護者 |
| 相關 | ADR-001（SCR ＝ 規格＋線框＋tokens） |

## 背景

ADR-001 把 SCR 定義成「資訊規格＋線框＋tokens」的三件套。但「SCR」字面是 screen（螢幕），造成兩個問題：

| # | 問題 | 證據 |
|---|---|---|
| 1 | 容器不只有「頁面」 | 四種容器含分步／彈窗／區塊，彈窗不是螢幕 |
| 2 | 與實體顯示器混淆 | KDS、看板才是真正的「螢幕」 |

教材因此長期混用「SCR／螢幕／線框」三種说法，學生會把「編號」當成「產物」。

## 驅動因素

- 產物是**線框**；`SCR-xx` 只是編號（ADR-001）
- 名稱會進入程式碼（資料夾名、故事路徑、檢查的 `screen` 欄位），只改文件不改 ID 等於留下一個錯的名字
- 已具備全量驗證能力（`verify-stories`、`smoke-dom`），改名風險可控

## 考慮過的選項

| 選項 | 優點 | 缺點 | 為什麼不選 |
|---|---|---|---|
| A. 只改中文用語（螢幕→線框），ID 仍是 SCR | 成本低 | 程式碼、資料夾、路徑永遠住著錯的名字；學生看資料夾就學錯 | 留下規格債 |
| **B. 全面改名 SCR→WIRE、scr-→wire-、display-08→wire-08** | 名稱與產物一致；機器與人看到同一個詞 | 11 個資料夾、23 條檢查、10 條故事路徑全部要改 | **採用** |
| C. 不改 | 零成本 | 混用持續，且與 ADR-001 衝突 | 不可接受 |

## 決定

採 B，一次改完、不留相容別名：

| 項目 | 改法 |
|---|---|
| 資料夾 | `scr-NN-slug` → `wire-NN-slug`；`display-08-pickup-board` → `wire-08-pickup-board` |
| 編號 | `SCR-NN` → `WIRE-NN` |
| 文件用語 | 指 UI 的一律「線框」；「螢幕」只保留給實體顯示器（KDS、看板、55 吋 4K） |
| 檔名 | `06_重算_SCR清單與狀態視圖.md` → `06_重算_WIRE清單與狀態視圖.md` |
| 程式 | 路徑、`screen` 欄位、正則、lint 過濾全部同步 |
| 歷史文件 | `08_CHANGELOG` 與 `ADR-001` **不改寫**（決策史要保留當時的用語） |

## 影響範圍

| 項目 | 影響 |
|---|---|
| 已改寫檔案 | 65 個（prototype 全部程式與頁面、11 個資料夾、現行文件） |
| 改名檔案 | 1（06_重算_WIRE清單與狀態視圖.md） |
| 不受影響 | 任務句內容、元素內容、AC 內容、Design.md、tokens、畫面本身 |

## 代價與風險

- **一次性大範圍改動**，若漏改會造成路徑錯誤 → 以新增的「命名一致性」檢查兜住（已通過）。
- 歷史紀錄（CHANGELOG／ADR-001）仍使用舊名稱，閱讀時需知道這是刻意的。

## 如何回滾

若改名造成不可修的破壞：以 `wire-` → `scr-` 反向替換即可（映射是一對一且無歧義）。但**不建議**，因為回滾會把名稱債再一次帶回來。

## 驗證方式

| 指標 | 標準 | 結果 |
|---|---|---|
| 命名一致性 | 程式與頁面無 `scr-`／`display-`／`SCR` | **✓ 通過** |
| 全套檢查 | lint／verify／selftest／smoke 全綠 | **✓ 通過** |
| 產出檔重生 | `13_STORIES`／`20_元素表` 由程式重新產生 | **✓ 完成** |
| 實體顯示器用語 | 「螢幕」僅用於 KDS／看板／尺寸描述 | **✓ 保留 14 處** |

## 執行後記（2026-10-28）

| 事件 | 說明 |

| 誤傷識別字 | 全域替換 `SCR → WIRE` 把 `SCREEN_ENTRY` 變成 `WIREEEN_ENTRY`（SCREEN = SCR + EEN），入口檢查因此失效 |

| 修正 | 改回 `SCREEN_ENTRY`；兩處檔案 |
| 教訓 | **全域字串替換要用字界（word boundary）或白名單**，不能直接 split/join 整段文字 |
