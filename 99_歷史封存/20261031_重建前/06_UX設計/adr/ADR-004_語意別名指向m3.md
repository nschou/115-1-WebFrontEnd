# ADR-004 語意別名改為指向 m3 色票（tokens 單一來源）

| 欄位 | 內容 |
|---|---|
| 編號 | ADR-004 |
| 狀態 | **已採用**（2026-10-29） |
| 提出者 | 課程教師（觀察「線框／彩色差異不大」時追出的色票問題） |
| 決策者 | 課程教師 |
| 受影響者 | 11 個 SCR 的視覺、DESIGN.md 範例、tokens.css |
| 相關 | ADR-001（三件套）、tokens 雙層設計 |

## 背景

`tokens.css` 有兩層：`--m3-*`（DESIGN.md／Stitch 原始 47 色）與 `--color-*`（畫面用的語意別名）。
實測後發現兩層**只有 4 / 12 相符**：

| 別名 | 畫面用的值 | DESIGN.md 的值 |
|---|---|---|
| `--color-text` | `#0F172A` | `#191c1e` |
| `--color-bg` | `#F8FAFC` | `#f7f9fb` |
| `--color-accent` | `#F97316` | `#fd761a` |
| `--color-success` | `#10B981` | `#005136` |

也就是說：**畫面用了 token，但用的不是 DESIGN.md 的那一套色**。
後果是「改 DESIGN.md 的色票，畫面不會跟著變」——這與課程主張的「tokens 是唯一來源」矛盾。

## 驅動因素

- 單一來源原則：換風格只能改一處
- `lint` 只驗「有沒有用 token」，驗不出「是不是同一套色」
- 顏色層靠人工對照，遲早漂移

## 考慮過的選項

| 選項 | 說明 | 結果 |
|---|---|---|
| **A** | 別名改指向 `var(--m3-*)` | **採用** |
| B | 承認別名是手調版，加註偏離原因 | 留下永久兩套色 |
| C | 刪掉 m3 層，只留別名 | 失去與 DESIGN.md 的對照 |

## 決定

採 A：11 個別名指向 m3；**4 個保留實色並註明原因**（M3 無對應語意）：

| 保留實色 | 原因 |
|---|---|
| `--color-warn` | M3 沒有 warning 語意 |
| `--color-accent-weak` | 極淺底，M3 無此階 |
| `--color-error-weak` | 同上 |
| `--color-disabled` | M3 以 on-surface 38% 表達，非實色 |

## 影響

| 項目 | 變化 |
|---|---|
| 文字 `#0F172A` → `#191c1e` | 略淺、略暖 |
| 底色 `#F8FAFC` → `#f7f9fb` | 幾乎無感 |
| 邊框 `#E2E8F0` → `#e0e3e5` | 幾乎無感 |
| 次要字 `#475569` → `#404847` | 偏綠灰 |
| 強調 `#F97316` → `#fd761a` | 略偏紅 |
| 成功 `#10B981` → `#005136` | **明顯變深**（KDS 完成、看板可取餐） |

## 順帶修正的可及性問題

淺橙底（`accent-weak`）上的橙字對比只有 **2.54**（改前 2.9，本來就不合格）。
新增 `--color-on-accent-weak: var(--m3-on-secondary-container)`（`#5c2400`），用於 `.tag-warn` 與 `.chip-s.guard`，對比提升到 **11.58**。

## 驗證

| 指標 | 結果 |
|---|---|
| 兩份 tokens.css（原型／DESIGN.md）值一致 | ✓ 115 個 token 全同 |
| 四層檢查 | ✓ 全部通過 |
| 顏色 token 使用 | 15 / 63 被引用（其餘為 m3 原始層） |
| 關鍵對比 | 文字 16.2、次要字 9.4、淺底深字 11.6（皆 ≥4.5） |

## 回滾

把 11 個別名改回實色即可（值列在上表）。但回滾等於承認「兩套色」，不建議。
