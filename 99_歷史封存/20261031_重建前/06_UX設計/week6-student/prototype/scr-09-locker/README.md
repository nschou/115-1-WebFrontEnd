# SCR-09 取餐櫃面板

| 項目 | 內容 |
|---|---|
| SCR | SCR-09（設施端，L1，768 直立） |
| 承接任務 | T12 開櫃取餐 |
| 承接狀態 | S6 → S7 |
| 觀看距離 | 1 公尺（標題 48px、按鍵高 120px） |

| 頁面狀態 | 顯示 | MSG |
|---|---|---|
| default | 輸入取餐號碼＋數字鍵盤 | — |
| loading | 驗證中 | — |
| error | 號碼或開櫃碼錯誤＋重新輸入 | — |
| success | 櫃門已開＋請取走 | MSG-14 |
| interrupted | 輸入逾時（安全） | — |

**不做的狀態**：empty（面板沒有「沒有資料」的情境）。
**檢查**：逾時一定要回到初始，不要把顧客的輸入留在畫面上。
