# SCR-08 取餐看板

| 項目 | 內容 |
|---|---|
| SCR | SCR-08（設施端，L2，1920×1080，**純顯示不可觸控**） |
| 承接任務 | T11 顯示可取餐號碼 |
| 承接狀態 | S6（只顯示店員已確認的） |
| 觀看距離 | 4 公尺（號碼 96px、標籤 32px、對比 ≥7:1） |
| 更新方式 | 時間驅動（號碼變了才換） |

| 頁面狀態 | 顯示 |
|---|---|
| default | 可取餐號碼格（3 欄）＋製作中次區＋時鐘 |
| loading | 更新中 |
| empty | 目前沒有可取餐號碼 |
| error | 連線中斷＋最後更新時間＋請詢問店員 |
| success | 新號碼以強調色標示，淡入 300ms 後靜止 |
| interrupted | 系統維護中 |

**三條規則**：①只顯示店員已確認的號碼 ②無任何互動元素 ③不只靠顏色（每格有「可取餐」文字）
