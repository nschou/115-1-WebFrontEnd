## v1.2｜2026-10-26｜線框改以 HTML 實作（pilot）

**決策**：線框不再只畫圖，改用 **HTML＋CSS＋JS**，一個螢幕一個子目錄，套 `DESIGN.md` 的 token。

**理由**：token 要被執行（不是被描述）／六態要可切換／「改一個 token 全站連動」可驗收／無障礙可做。

**五條硬規則**：①只用 token ②六態可切換 ③灰階優先 ④一目錄一 SCR、檔案結構固定 ⑤**HTML 不取代 AC**。

**已完成（pilot）**
