# SCR-04 結帳

| 項目 | 內容 |
|---|---|
| SCR | SCR-04（顧客端，L3） |
| 承接任務 | T4 付款 |
| 承接狀態 | 待付款 → 處理中 → 成功／SX2 付款失敗／待確認 |
| 進入條件 | SCR-03 必填欄位通過 |

| 頁面狀態 | 對應 | 顯示重點 | MSG |
|---|---|---|---|
| default | 待付款 | 金額、付款方式 | MSG-06 |
| loading | 處理中 | 「請不要關閉畫面」 | MSG-07 |
| empty | 無待付 | 回菜單 | — |
| error | SX2 | 「付款沒有完成」＋重試／換方式 | MSG-08 |
| success | 已付款 | 開始準備＋取餐時間 | MSG-09 |
| interrupted | 待確認 | 銀行確認中、不重複扣款 | MSG-10 |

**檢查**：處理中要禁用返回（IX-05）；失敗文案不得寫「交易失敗」這種無法行動的話。
