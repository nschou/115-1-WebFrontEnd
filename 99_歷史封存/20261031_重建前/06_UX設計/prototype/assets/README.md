# assets

| 檔案 | 用途 | 誰可以改 |
|---|---|---|
| `tokens.css` | Design.md 的 token（顏色／間距／字級／圓角／陰影） | **只由「換版程序」改**：改這裡＝換風格 |
| `wire.css` | 線框模式（去飽和）、開發列樣式 | 可改，但不得放任何顏色值 |

> **同步來源**：`05_AI輔助風格設計/06_新版_Design規格驅動/toolkit/範例_DESIGN_10章_平衡現代/tokens.css`。
> Design.md 換版（v1.1）時，重新複製此檔即可；不要在這裡手改。

## 為什麼 token 要獨立成一個檔

1. **它是「可替換性契約」的具體證據**：改 `--color-primary` 一個值，所有畫面連動 → 通過；
   某頁沒連動 → 那一頁寫死了色碼，退回。
2. **它是驗收工具**：第 5 週教的「改一個 token 看有沒有連動」，在這裡每天都能跑。
3. **它是 spec 的對照**：`tokens.css` 的變數名＝`DESIGN.md` 的 token 名，一一對應。
