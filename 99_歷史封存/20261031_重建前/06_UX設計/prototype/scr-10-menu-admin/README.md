# SCR-10 菜單維護

| 項目 | 內容 |
|---|---|
| SCR | SCR-10（老闆端，L1，768 平板） |
| 承接任務 | T13 維護菜單（含廚師確認供應） |
| 承接狀態 | 上架／售完／隱藏 |
| 進入條件 | 後台登入（決策 6：數位菜單） |

| 頁面狀態 | 顯示 | MSG |
|---|---|---|
| default | 品項列表＋供應開關＋儲存 | — |
| loading | 骨架 | — |
| empty | 尚無品項 → 新增 | — |
| error | 儲存失敗（變更未送出） | — |
| success | 已儲存＋幾分鐘內生效 | — |
| interrupted | **他人已修改（衝突）** | — |

**為什麼要有 interrupted**：這是多人編輯最常見的錯，也是 AI 最容易漏的狀態。
**圖位**：列表縮圖 ＋ 「上傳／更換品項照」。依據＝老闆需要照片品質管理。
