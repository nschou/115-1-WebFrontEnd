## 1. 選定市場

### 市場名稱

**新型態數位複合式連鎖**（使用者選定第 3 項）

### 研究範圍

- **地理背景**：台灣早餐餐飲市場。
- **分析單位**：依商業模式與營運邏輯區隔，不依單一品牌區隔。
- **服務範圍**：單店至小型連鎖的顧客點餐、支付、訂單處理、等待進度與取餐服務。
- **主要情境**：工作日早餐、通勤、外帶、內用與預約取餐。
- **研究用途**：選擇最適合本課程服務設計與前端實作的目標市場，不作完整投資判斷。

### 選擇理由

1. **系統開發複雜度較完整**：可涵蓋顧客點餐、支付、廚房接單、訂單進度、取餐、庫存與經營資料，能形成前台、後台與支援系統的完整服務流程。
2. **數位化潛力較高**：既有研究摘要描述此類業態可能整合 POS、預約、App、CRM 與取餐服務，數位系統與營運痛點的連結清楚；相關品牌數據仍待原始來源查核。
3. **顧客痛點適合服務設計**：品項多、尖峰集中、等待時間不確定與取餐資訊不清楚，可轉化為 CJM、服務藍圖、狀態流程與前端互動需求；痛點強度尚未由使用者研究驗證。
4. **教學涵蓋度高**：可以同時示範顧客、店員、廚房與店長等角色，以及手機優先介面、例外處理、訂單狀態、POS 報表等功能。
5. **可縮小為單店示範**：先以 1 家門市和有限人力示範核心流程，再把會員、AI 預測與多店管理列為未來方向，適合課程範圍控制。

以上理由說明本市場為本課程的選定目標。這是依課程設計適配性與既有研究摘要形成的結論，不代表此市場在現實商業環境中一定最有利可圖。

### 不選其他市場的理由

| 市場 | 不選作本課程主要目標的理由 | 資料性質 |
|---|---|---|
| 傳統社區型與個體獨立早餐店 | 數位化需求與系統流程相對少；若要展示完整訂餐管理系統，需建立較多案例假設。但此市場仍適合研究輕量化點餐或 POS 升級。 | 研究依據＋設計評估，部分待查核 |
| 老字號加盟連鎖 | 具備標準化與數位升級需求，但總部與加盟店的權責會增加案例複雜度；作為比較對象保留。 | 研究依據＋設計評估，待加盟店訪談 |
| 便利商店即食與組合餐 | 數位系統豐富，但核心是零售、供應鏈與即食商品，不是現點現做早餐店的廚房與取餐服務；直接套用會改變原本的服務問題。 | 研究依據＋設計評估，部分待查核 |
| 行動餐車與微型攤販 | 速度與移動性強，但固定設備、廚房後台、取餐與店內角色較少，不利於展示完整服務藍圖。 | 研究依據＋設計評估，待現場觀察 |
| 精緻獨立早午餐與風格主題門市 | 核心價值偏向空間、餐點體驗與較長用餐時間，與本專案聚焦的通勤、外帶、尖峰取餐不同。 | 研究依據＋設計評估，部分待查核 |

### 選擇判斷限制

- 尚未完成顧客訪談、店家訪談、問卷或現場等待時間觀察。
- 六大市場的客單價、等待時間與毛利率可能有不同計算定義，不能直接視為完全可比的統計值。
- 既有研究摘要中的市場規模、門市數、成長率與品牌數位訂單比例，尚未全部回查至官方原始資料。
- 因此，本次選定是「課程服務設計適配性」的使用者選擇與研究支持結論，不是市場投資排名。

### 比較補充

- **數位化程度**和**系統需求**是依既有研究摘要與課程服務設計目的做的初步分級，不是統一量表測量。
- **等待時間**在不同市場可能指現場排隊、製作、預約取餐或候位，不能直接互相比較。
- **毛利率**未列入本結論表，因為各來源的計算層級與定義尚未統一；不使用毛利率直接判定市場優劣。
- 新型態數位複合式連鎖的「高數位化」是市場模式描述與設計推導，不能推論每一家店都已具備完整 App、KDS 或 CRM。

## 3. 約束鏈

```text
選定「新型態數位複合式連鎖」
→ 目標客群：彈性工時者、年輕上班族、需要快速取餐的通勤顧客
→ 老闆傾向：提高數位訂單與資料可見性，改善尖峰營運，為未來展店保留擴充性
→ 顧客期望：快速、清楚、可預期、具有現代科技感但不混亂
→ CJM 情緒需求：降低等待期間的不確定與焦慮；放大掌控感、安心感與效率感
→ Blueprint 方向：顧客、店員、廚房與店長之間需要清楚的訂單交接和狀態更新
→ 風格方向：清楚、現代、可信賴、有效率（風格假設，需比較驗證）
→ 功能需求：數位菜單、分群瀏覽、點餐確認、線上或現場付款、訂單狀態、預估取餐時間、取餐通知、店員／廚房接單、POS 記錄
```

### 約束鏈說明

- 市場選擇提高數位方案的優先度，但**不唯一決定使用 App**；網站、LINE、App 或第三方平台仍需後續比較。
- 市場選擇支持數位菜單、訂單狀態與取餐通知等方向，但不代表初期就應導入 AI 預測。
- 高數位化不等於所有流程都自動化；付款失敗、品項缺貨、廚房確認與取餐交付仍需要人工角色。
- 風格方向目前只是設計候選語意，不是已核准的色彩、字體、圓角或動效規格。
- 市場選擇約束後續方向，但不直接決定每個方案。
