## 調研方法（從第 5 週講義抽取）

### 步驟 1：市場定位分析
從 `01_market.md` 的市場選擇，分析關鍵詞（如「數位」「複合式」「連鎖」）如何約束每項決策的方向。市場定位提高某些方案的優先度，但仍需從營運需求、成本與限制做決定。

### 步驟 2：三層方案分類
對每項決策，區分三層：
- 基本方案：靠人工操作或基礎數位工具
- 規則自動化：系統按設定規則自動執行（POS扣庫存、低庫存提醒——不是AI）
- AI增強：ML模型預測或優化（需累積數據，初期可能不採用）

### 步驟 3：逐項決策定案
從 `04_blueprint.md` 的選項版中，為每項決策填入：
- 採用方案（選A/B/C，附理由）
- 理由（為什麼選這個）
- 代價與限制（選了這個的代價是什麼）
- AI增強方向（未來可以怎麼升級）
- 導入條件（什麼時候可以導入AI版本）

### 步驟 4：操作流程推導
某些決策需要補充操作流程：
- KDS操作流程：從「廚房接收方式」決策推導，含訂單狀態流
- 預估取餐時間：從「進度通知」決策推導，分基本/規則/AI三層
- 缺貨同步：從「菜單維護」和「庫存盤點」決策推導
- POS與庫存時序：釐清POS上線和庫存串接的先後順序

### 步驟 5：因果鏈推導
為每項決策記錄回溯：依據什麼、回溯到哪、來源性質、驗證狀態。

### 步驟 6：設計交接摘要
從Persona推導品牌人格、從CJM推導情緒需求、從Blueprint推導服務承諾。風格預設標為「待提出候選」——不在baseline中定義。
