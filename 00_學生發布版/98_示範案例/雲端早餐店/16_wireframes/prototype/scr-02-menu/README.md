# SCR-02 菜單

| 項目 | 內容 |
|---|---|
| SCR | SCR-02（顧客端，L2） |
| 承接任務 | T1 決定、T2 客製加購 |
| 承接狀態 | 有品項／全售完／SX1 缺貨 |
| 進入條件 | 由 SCR-01 進入 |

| 頁面狀態 | 顯示重點 | MSG |
|---|---|---|
| default | 分群 chips、品項卡、售完灰化、底部購物車條 | — |
| loading | 骨架 | — |
| empty | 全部售完 | — |
| error | 載入失敗 | MSG-18 |
| interrupted | 選中品項售完 → 換品項 | MSG-05 |

**檢查**：售完品項的「＋」要 disabled，不是隱藏（讓顧客知道有這項）。
**圖位**：卡片縮圖 1:1（88px）。依據＝顧客「要不要點」的決策需要實物照。
