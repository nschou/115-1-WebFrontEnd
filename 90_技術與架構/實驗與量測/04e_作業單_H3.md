> 這一單元有 **A（無 AI）、B（有 AI）、C（驗證報告）** 三部分。
> 繳交到 Teams 作業區；檔名見最後一節。

## 1. A 題（無 AI，40%）

不使用 AI 完成：

1. 為「建立訂單」寫一份 schema（欄位、型別、規則）。
2. 從 schema 推出型別（寫出你會怎麼做）。
3. 寫出錯誤結構四欄，並為三個情境各寫一組（缺欄位、格式錯、衝突）。
4. 指出一個「外部資料沒有驗證」的邊界。

## 2. B 題（有 AI，30%）

同題型，換一個端點（例如「取消訂單」），可用 AI：

1. 先寫 schema 與錯誤規則，再請 AI 產出。
2. 存 prompt 歷程與 token 截圖。
3. 找出 AI 版本至少 2 個問題（例如漏 retryable、沒有驗證）。
4. 修正並寫出你的版本。

## 3. C 驗證報告（30%）

| 欄位 | 內容 |
|---|---|
| 測試案例 | 至少 5 個（含 3 個錯誤情境） |
| 型別與驗證 | 證明兩者共用同一份定義 |
| AI 錯在哪 | 至少 2 個 |
| 怎麼抓到 | 用什麼方法 |
| 反思 | 規格會多寫什麼 |
