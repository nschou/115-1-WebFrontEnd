# 06_知情同意書（教學研究）

> 本文件用於說明研究目的、資料用途與你的權利。**參與與否不影響成績。**

## 1. 研究目的

了解「AI 輔助」對學習與專案完成的影響，包括：學習成效、專案品質、使用方式與動機變化。

## 2. 會收集哪些資料

| 資料 | 用途 |
|---|---|
| 前測、後測、段考成績 | 比較學習成效 |
| 課堂任務成績 | 比較有 AI／無 AI 的表現 |
| prompt 歷程與 token 截圖 | 分析使用方式 |
| 問卷（ARCS、使用習慣） | 了解動機與態度 |
| 課堂觀察紀錄 | 了解學習過程 |

## 3. 資料怎麼處理

- 學號會轉成代碼，報告中不出現姓名。
- 資料只供本研究與教學改進使用。
- 原始檔保存於校內，不對外提供。
- 研究結束後保存三年，期滿刪除。

## 4. 你的權利

| 權利 | 說明 |
|---|---|
| 自由參與 | 不參與不會影響成績與評量 |
| 隨時退出 | 退出後可要求刪除已收集資料 |
| 查看結果 | 可向授課教師索取個人資料 |
| 提問 | 對研究有疑問可隨時詢問 |

## 5. 不參與的替代方式

不參與者仍要完成課程作業與考試（這是課程要求），但**資料不納入研究分析**。
