# 01_crossover 任務設計與評分

> 目的：讓同一個人在「有 AI」與「無 AI」下做**同構任務**，用來分辨「AI 的幫助」與「本來就會」。
> 原則：同題型、同難度、不同資料；同一份 rubric；兩組交換。

## 1. 交換方式（不分組）

每個學生自己完成甲、乙兩題；順序在輪次間交換：

| 輪 | 任務甲 | 任務乙 |
|---|---|---|
| R1 | 無 AI | 有 AI |
| R2 | 有 AI | 無 AI |

> 不需要分組：每人都有一次「無 AI」與一次「有 AI」，自己當自己的對照。

## 2. 無 AI 任務的規則

| 允許 | 禁止 |
|---|---|
| 課程講義、自己的筆記 | 任何 AI 工具 |
| 瀏覽器開發者工具 | 詢問同學（可標記放棄） |
| 課前提供的規格片段 | 上網搜尋範例程式碼 |

> 若違規，該任務以 0 分計，並記錄為「無效樣本」（不列入分析）。

## 3. 有 AI 任務的規則

| 要求 | 說明 |
|---|---|
| 存 prompt 歷程 | 每一則提問與回覆摘要 |
| 截圖 token | 含日期、模型、token 用量 |
| 標記採用與否 | AI 給的程式碼，哪些用了、哪些改了 |

## 4. 評分 rubric（三輪通用）

| 項目 | 比重 | 判準 |
|---|---:|---|
| 正確性 | 40 | 符合規格與狀態規則 |
| 完整度 | 25 | 必填欄位、錯誤處理、邊界 |
| 可讀性 | 15 | 命名、結構、註解 |
| 驗證 | 20 | 有測試或檢查，且說得出怎麼驗 |

## 5. 資料欄位（每筆任務一列）

| 欄位 | 說明 |
|---|---|
| round | R1／R2 |
| student | 學號 |
| task | 甲／乙 |
| condition | AI／noAI |
| score | 0–100 |
| minutes | 實際用時 |
| tokens | 截圖上的用量 |
| turns | 對話訊息數 |
| prompt_types | 分類計數 |
| note | 異常（違規、缺件） |

## 6. 分析方式

| 問題 | 分析 |
|---|---|
| AI 有沒有幫助？ | 同輪「有 AI」與「無 AI」的分數差（配對比較） |
| 幫助在哪？ | 看 rubric 哪個子項差距最大 |
| 幫助有多大？ | 效果量（配對差異的平均與標準差） |
| 是否依賴？ | 有 AI 分數高、但後測（無 AI）沒進步 → 依賴訊號 |
