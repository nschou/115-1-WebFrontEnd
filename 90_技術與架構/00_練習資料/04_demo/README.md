# 04_demo｜示範網站怎麼用

> 這一頁是給「需要看畫面」的步驟用的。三個檔案要一起看：

| 檔案 | 角色 |
|---|---|
| `index.html` | 頁面結構，並引入 CSS 與 JS |
| `style.css` | 樣式與設計變數（tokens） |
| `app.js` | 用假資料產生四張卡片 |

## 怎麼打開

| 方法 | 步驟 |
|---|---|
| 直接開 | 雙擊 `index.html`（瀏覽器會載入同資料夾的 CSS 與 JS） |
| 本機伺服器 | 在 `04_demo` 資料夾執行 `python -m http.server 8000`，開 `http://localhost:8000` |

## 刻意留下的三個觀察點

1. `<script>` 放在 `<head>` 且沒有 `defer` → 會阻塞解析（第 2 講）。
2. `--color-primary` 是 `#1d4ed8`，但 `.badge` 寫死 `#2563eb` → 同一種藍有兩個來源（第 3 講）。
3. 只有四種狀態，缺「錯誤」與「空資料」→ 可補六態（第 4 講）。

> 改 `style.css` 後重新整理，就會看到變化；這就是「有 HTML 引入 CSS」才能觀察的原因。
