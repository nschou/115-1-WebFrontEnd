# 01_系統摘要｜雲端早餐店

> 狀態代號：S1 草稿／S2 已下單／S3 已確認／S4 製作中／S5 製作完成（待店員確認）／S6 可取餐／S7 已取餐；SX1–SX4 為例外（缺貨／付款失敗／通知未送達／修改待確認）。

## 四層

| 層 | 這個系統用什麼 |
|---|---|
| 用戶端 | 顧客手機瀏覽器、店員平板 |
| 邊緣 | CDN 快取靜態檔 |
| 伺服器 | Next.js（Bun 執行） |
| 資料層 | Neon serverless PostgreSQL |

## 角色

| 角色 | 主要動作 |
|---|---|
| 顧客 | 看菜單、下單、看狀態、取餐 |
| 店員 | 接單、入櫃、收款 |
| 廚師 | 回報製作完成 |
| 老闆 | 改菜單、看報表 |

## 頁面

| 頁面 | 誰用 | 主要狀態 |
|---|---|---|
| 菜單頁 | 顧客 | loading／empty／error |
| 訂單狀態頁 | 顧客 | S1–S7＋SX |
| 店員接單頁 | 店員 | 待接單／已接單 |
| 廚師看板 | 廚師 | 製作中／完成 |
| 老闆報表 | 老闆 | 今日／本週 |

## 資料表

| 表 | 欄位 |
|---|---|
| `orders` | id、status、created_at |
| `order_items` | order_id、name、quantity |
| `menu_items` | id、name、price、available |
| `pickup_numbers` | number（唯一）、order_id |
| `lockers` | id、number、status |

## API

| 方法 | 路徑 | 用途 |
|---|---|---|
| GET | `/menu` | 菜單 |
| POST | `/orders` | 建立訂單 |
| GET | `/orders/{id}` | 查訂單 |
| PATCH | `/orders/{id}` | 改狀態 |
| GET | `/events` | SSE 事件 |

## 三條資料線

| 線 | 從 | 到 |
|---|---|---|
| 讀取 | 資料庫 | 畫面 |
| 寫入 | 畫面 | 資料庫 |
| 通知 | 伺服器 | 其他端 |
