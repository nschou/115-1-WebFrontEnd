# 第 0 講｜學生操作手冊：把環境裝起來

> 你要交出：**一個能啟動的 Next.js 專案、一個雲端資料庫、一張 Prisma 建好的表、一個改過的畫面**。
> 每一步都有「這樣算完成」。

## Step 0：先確認你在哪裡

| 檢查 | 指令 | 你的結果 |
|---|---|---|
| 作業系統 | Windows 10／11 | |
| 終端機 | PowerShell 或 Windows Terminal | |
| 網路 | 可連外網 | |

這樣算完成：你能打開終端機並貼上指令。

## Step 1：安裝 Bun

````powershell
powershell -c "irm bun.sh/install.ps1 | iex"
````

關掉終端機再開，然後：

````powershell
bun -v
````

這樣算完成：畫面出現版本號（例如 `1.x`）。

## Step 2：安裝 Node.js（備援）

| 做法 | 說明 |
|---|---|
| 官網 LTS | 下載安裝檔，一路下一步 |
| 版本管理 | 用 `fnm` 或 `nvm` 切換版本 |

````powershell
node -v
````

這樣算完成：出現 `v22` 或以上的版本號。

## Step 3：建立 Next.js 專案

````powershell
bunx create-next-app@latest breakfast-app
cd breakfast-app
````

選項建議：TypeScript「是」、ESLint「是」、Tailwind「是」、App Router「是」。

這樣算完成：資料夾裡看得到 `app/`、`package.json`。

## Step 4：啟動並看到畫面

````powershell
bun run dev
````

開 `http://localhost:3000`。

這樣算完成：瀏覽器看到 Next.js 預設頁；終端機沒有紅色錯誤。

## Step 5：建立 Neon 資料庫

1. 到 Neon 官網註冊，建立一個專案。
2. 複製 **pooled** 連線字串（主機名稱含 `-pooler`）。
3. 在專案根目錄建立 `.env`：

````text
DATABASE_URL="postgresql://...-pooler...?sslmode=require"
````

4. 建立 `.env.example`，只保留欄位名稱。

這樣算完成：你能貼出「有 `-pooler` 的連線字串」，且 `.env` 沒有進 Git。

## Step 6：安裝 Prisma 並建表

````powershell
bun add -d prisma
bun add @prisma/client
bunx prisma init --datasource-provider postgresql
````

在 `prisma/schema.prisma` 加一個模型：

````prisma
model Order {
  id        String   @id @default(cuid())
  status    String
  createdAt DateTime @default(now())
}
````

````powershell
bunx prisma migrate dev --name init
````

這樣算完成：終端機顯示遷移成功；`prisma/migrations` 出現資料夾。

## Step 7：證明資料庫真的通了

````powershell
bunx prisma studio
````

新增一筆 `Order`，重新整理頁面還在。

這樣算完成：你能在 Studio 看到那筆資料。

## Step 8：安裝 shadcn/ui 並改一個畫面

````powershell
bunx --bun shadcn@latest init
bunx --bun shadcn@latest add button
````

在 `app/page.tsx` 用一個 `Button`，改文字與顏色變數。

這樣算完成：畫面出現按鈕，且顏色來自 Tailwind 類別或設計變數。

## Step 9：從資料庫讀一筆資料

在 `app/page.tsx`（server component）用 Prisma 查 `Order`，把 `status` 顯示出來。

這樣算完成：畫面顯示你在 Studio 新增的那筆狀態。

## Step 10：交件檢查

- [ ] `bun -v` 與 `node -v` 都有版本號
- [ ] `bun run dev` 可啟動，`localhost:3000` 有畫面
- [ ] `.env` 有 pooler 連線字串，且沒進 Git
- [ ] `prisma migrate` 成功，Studio 看得到資料
- [ ] shadcn 按鈕出現在畫面上
- [ ] 頁面讀得到資料庫的一筆資料
