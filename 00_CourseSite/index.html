BEFORE ANY CODE

先紙筆，再畫面，最後才是契約

三層各回答一個問題；任何一層偷跑，後面就要重做。看一頁流程圖 →

1

紙筆：對不對

誰、在什麼狀態、拿什麼、交給誰、代價與例外。

判準 紙＋筆＋說話跑得完｜不含 工具、畫面

2

畫面：順不順

任務變成什麼介面、什麼時候看到什麼。

判準 每態畫得出、說得出理由｜不含 實作、元件庫

3

契約：說清楚

18_spec：可追溯、可驗收、不含工具。

判準 可被研究與計畫消費｜不含 技術選擇

紙筆測試的兩個極限：

測不出規模（尖峰 3 分鐘 40 單）、測不出延遲與競態（兩人同時改同一單）——用「資訊流」的量化參數補。

AI COLLABORATION

先給 AI 證據，再要求 AI 推導

不可跳過上游
1. 提供上下文

附上本階段輸入、文件索引、ID 規則與已知限制。

2. 禁止虛構

沒有來源的內容必須標成「待確認」，不能自行補成事實。

3. 要求追溯

每個結論都要回指來源、欄位、狀態或決策。

4. 人工驗證

AI 產生的是草稿；正式文件要經過檢查與人工交叉比對。

使用方法：選擇階段 → 閱讀輸入與完成條件 → 複製 Prompt → 附上自己的文件 → 要 AI 先列出缺資料與矛盾，再產生草稿。
