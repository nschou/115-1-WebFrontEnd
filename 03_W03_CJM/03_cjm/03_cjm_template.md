## 5. 涉及物件與資訊需求（新增）

> CJM 不寫物件的規格（那是內容模型的事），但**必須記「顧客在這個接觸點需要看到什麼，才能做決定」**。

| 階段 | 接觸點 | 涉及物件 | 需要看到的資訊 | 缺少會怎樣（情緒影響） |
|---|---|---|---|---|
| | | | | |

> 例：菜單接觸點涉及「菜單品項」，需要**實物照（份量感）**與價格；缺少 → 不敢點、來回滑動、情緒下降。
> 這一欄是「為什麼顧客端要有照片」的唯一依據來源。
