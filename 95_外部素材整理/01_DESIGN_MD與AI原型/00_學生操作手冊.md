# 學生操作手冊｜做出你自己的 DESIGN.md

> 你要交出：**一份 DESIGN.md 與一頁用它產生的原型**。
> 每一步都有「這樣算完成」。

## Step 0：先判斷來源

| 問題 | 你的答案 |
|---|---|
| 有現成產品或網站嗎 | |
| 有想參考的網站嗎 | |
| 完全沒有方向嗎 | |

這樣算完成：你能選出「自有產品／參考網站／設計庫」其中一條路。

## Step 1：取得 DESIGN.md

### 1A 有自有產品

1. 準備產品的網址、截圖或原始碼。
2. 用 designmd.cc 貼上網址，或請 AI 依截圖與 CSS 整理。
3. 存成專案根目錄的 `DESIGN.md`。

這樣算完成：檔案裡有顏色、字體、間距三類內容。

### 1B 有參考網站

1. 打開 designmd.cc。
2. 貼上參考網站的網址。
3. 下載產出的 DESIGN.md，改名成 `DESIGN.md`。

這樣算完成：你能指出「這份規範是從哪個網址來的」。

### 1C 完全沒有方向

1. 開 getdesign.md，挑 2–3 個風格接近的品牌。
2. 用 `npx getdesign@latest list` 看清單，`npx getdesign@latest add <品牌>` 下載。
3. 選一份當起點，不要混三份。

這樣算完成：你有一份 DESIGN.md，並寫下「為什麼選它」。

## Step 3：改成「你的」版本

| 動作 | 說明 |
|---|---|
| 換品牌色 | 用你的主色，保留對比 |
| 刪用不到的元件 | 只留這門課會用到的 |
| 加三條禁止事項 | 例如「不得用顏色當唯一狀態」 |
| 標優先級 | 必守／建議 |

這樣算完成：檔案裡看得到你的品牌調整與至少三條禁止事項。

## Step 4：交給 AI 畫一頁

把 `DESIGN.md` 附上，貼這段提示：

```text
請先讀 DESIGN.md，然後只做「訂單狀態頁」這一頁。
1. 先列出會用到的元件與狀態（loading／empty／error／success）。
2. 再畫版面，標明用了哪幾條 DESIGN.md 規則。
3. 不要新增 DESIGN.md 沒有的顏色與字級。
```

這樣算完成：AI 的輸出有列出元件與狀態，且沒有自創顏色。

## Step 5：手動修改實驗（四項）

> 目的是「看見規則的作用」：先故意改壞，觀察後果，再改回。
> 每次實驗前**備份** `DESIGN.md`，做完還原。

### 實驗 1：把文字改成低對比

| 項目 | 內容 |
|---|---|
| 改哪裡 | 主色按鈕的文字色（on-primary） |
| 改前 | 白色文字 on 藍色底 |
| 改後 | 淺灰 `#CCCCCC` on 同一個藍 |
| 觀察 | 文字是否還清楚；對比夠不夠 |
| 記錄 | 對比比值（用線上對比檢查器） |

這樣算完成：你能說出「低於 4.5:1 會怎樣」，並改回合格色。

### 實驗 2：把圓角改成 0

| 項目 | 內容 |
|---|---|
| 改哪裡 | `--radius-card` |
| 改前 | 12px |
| 改後 | 0 |
| 觀察 | 所有卡片是否一起變；有沒有元件「沒跟著變」 |

這樣算完成：若有不跟著變的元件，你能指出它把圓角**寫死**了，並改成變數。

### 實驗 3：把斷點改小

| 項目 | 內容 |
|---|---|
| 改哪裡 | 手機斷點 `640` |
| 改前 | 640px |
| 改後 | 320px |
| 觀察 | 在 375px 寬的畫面下，版面是否爆掉 |

這樣算完成：你能指出「哪一個區塊先壞」，並改回 640。

### 實驗 4：刪掉一條禁止事項

| 項目 | 內容 |
|---|---|
| 改哪裡 | DESIGN.md 的「禁止事項」 |
| 刪掉 | 「不得用顏色當唯一狀態提示」 |
| 動作 | 用同一份 DESIGN.md 讓 AI 重產一頁 |
| 觀察 | 產出是否只剩顏色、沒有文字或圖示 |

這樣算完成：你能說明「規則被刪掉後，AI 就會退回預設做法」，並把規則加回。
