# D_交付物｜6 份交付物，18 檔證據

> 名詞：降級（主要管道失效時改用替代管道，例：通知送不出去就改看店內看板；不是把功能關掉）。

> 這個資料夾是「學生實際要交的東西」。其餘 18 個檔案是**證據**：用來證明你為什麼這樣決定，
> 老師會抽查，但你不必每週把它們維持在滿分狀態。

## 產生方式

```
node gen-deliverables.mjs
```

只讀上游（`05_objects`／`07_decisions`／`17_UserStory-I_AC`／`16_wireframes/prototype`），不另外手寫第二份真相。
