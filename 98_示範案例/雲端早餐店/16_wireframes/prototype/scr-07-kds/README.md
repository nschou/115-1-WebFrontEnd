# SCR-07 廚房顯示器（KDS）

| 項目 | 內容 |
|---|---|
| SCR | SCR-07（廚房端，L3，1920×1080） |
| 承接任務 | T10 排序與回報 |
| 承接狀態 | S2／S4／S5 |
| 觀看距離 | 2 公尺（內文 32px、訂單號 48px、按鈕高 120px） |

| 頁面狀態 | 對應 | 顯示重點 | MSG |
|---|---|---|---|
| default | S2／S4 | 佇列、計時器、開始製作 | MSG-20 |
| loading | — | 卡片骨架 | — |
| empty | 無單 | 目前沒有待製作 | MSG-21 |
| error | 斷線 | 重試中，已完成的不遺失 | MSG-22 |
| success | S5 | **完成（待店員確認）**，不通知顧客 | MSG-23 |
| interrupted | SX1 | 缺貨標記＋通知店員 | MSG-24 |

**業務規則**：按完成後仍停在「待店員確認」，看板不會出現號碼——這條規則在 UI 上就是兩個狀態。
**刻意不給圖**：廚師只要品名、份量、客製；加圖會降低掃視速度。
